# Berkeley BSIM3 acknowledgment

CoreSpice acknowledges the University of California, Berkeley BSIM Research
Group. The isolated native BSIM3 evaluator incorporates BSIM3 3.3.0 released
July 29, 2005. Copyright notices remain in each original file, and
[Berkeley terms](Kernel/B3TERMS_OF_USE) apply to those files. CoreSpice's
adapter and safe Swift API are separate additions. No charge is imposed for
the University of California code itself.

[Provenance](Kernel/upstream.json) pins the official archive and original source
hashes. `Kernel/adapt_upstream.py <extracted-original-directory>` reproduces
adapted physics files. The kernel design documents every adapter difference.
